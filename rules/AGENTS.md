# Exa web search

The libraries, APIs and tools in this project change every day. When a task depends on information outside the repository, use Exa instead of relying on training data.

- Use `web_search_exa` to find current documentation, changelogs, issues, real-world examples and news.
- Use `web_fetch_exa` to read a URL the user shares, or a search result whose content is not enough.
- Cite the URL of every source you use.

Clients may prefix tool names (for example, `mcp_exa_web_search_exa`). Use the available tool whose name ends with `web_search_exa` or `web_fetch_exa` and whose description matches the operation.
